# 외부 자료와 배포 범위

## Epic 3인칭 템플릿

`Content/Characters/Mannequins`의 포함 파일 115개는 설치된 Unreal Engine 5.3의 `Templates/TemplateResources/High/Characters/Content`에 대응하는 경로가 있습니다. 이 중 114개는 바이트 단위로 동일하고, 1개는 같은 템플릿 경로에서 수정된 파일입니다. 템플릿 기반 캐릭터·입력·코드의 Epic 저작권 고지를 유지합니다.

Epic의 Examples 배포 조항을 근거로 템플릿 예제를 구분했습니다. 프로젝트 전체나 다른 외부 팩에 이 권한을 확장하지 않습니다.

- [Unreal Engine EULA, Examples 및 Section 5(b)](https://www.unrealengine.com/eula/unreal)
